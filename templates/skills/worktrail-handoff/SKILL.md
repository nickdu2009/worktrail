# Worktrail Handoff

Use this skill before ending a session, compacting context, or switching tools.

1. Run `worktrail handoff`.
2. Summarize the active state, current diff intent, validation, and next step.
3. If Worktrail creates candidates, leave them pending for `/worktrail-review`.
4. Do not promote, merge, or discard without explicit user confirmation.
