# Worktrail Context

Use this skill when starting substantial project work, resuming an old task, continuing previous work, loading project memory, or when the user asks to start work, continue a previous task, load context, or load project context.

1. Run `worktrail context "$ARGUMENTS"`.
2. Read the Context Pack into the current conversation.
3. Follow any active state, constraints, and next steps in the pack.
4. If the task is long or risky, start or update state with `/worktrail-state`.
